# Support

This is a community-maintained project with best-effort support. There is no paid support service or guaranteed response time.

## Before asking for help

1. Review the [README](README.md#current-implementation) to see which pages and controls are complete.
2. Follow [Installation](docs/installation.md), then check the [Troubleshooting guide](docs/troubleshooting.md) and [FAQ](docs/faq.md).
3. Search the [repository issues](https://github.com/Brajesh31/bondforge-studio/issues) for a similar report.

## Report a bug or request a feature

Open an issue in the [GitHub repository](https://github.com/Brajesh31/bondforge-studio/issues) and include:

- What you expected and what happened.
- The page path and steps to reproduce the behavior.
- Browser, operating system, and viewport size when relevant.
- The commit or branch and the commands used to run or build the site.
- Sanitized console or build output and screenshots that do not contain private information.

For a feature request, describe the visitor need and desired behavior. For forms or booking, specify where submitted information should go and how it should be protected; the current frontend has no backend submission service.

## Protect private information

Do not post passwords, API keys, deployment credentials, private customer information, session data, or unredacted logs in a public issue. Do not use a public issue to report a security vulnerability; use the private process in [SECURITY.md](SECURITY.md). For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
